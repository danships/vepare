# Initial project

This repository is a pnpm workspace containing a single Next.js application in `packages/web`.

## Prerequisites

- Node.js 24.x
- Corepack

```bash
corepack enable
pnpm install
pnpm dev
```

The web app is available at http://localhost:3000. Run `pnpm lint` for quality checks and `pnpm build` for a production build.
